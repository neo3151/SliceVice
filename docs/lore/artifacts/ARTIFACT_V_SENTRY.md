# ARTIFACT: THE V-SENTRY PROTOTYPE (1988)

**TYPE**: High-Security Hardware Encryption Module  
**ORIGIN**: Vanguard Signals Intelligence (Black Site)  
**STATUS**: SECURED // NON-COMPLIANT

The **V-Sentry Prototype** is a heavy, industrial hardware module stolen during the Stiltsville breach. It contains the raw, unencrypted geolocation data for the Vanguard's entire Florida surveillance net.

### TECHNICAL OVERVIEW
Designed to interface with the Cadillac/Pontiac high-output alternators of the era, the V-Sentry allows a user to "Ghost-Drive"—intercepting and jamming Vanguard tracking signals in a 500-yard radius. It isn't software; it's a physical circuit-breaker for the city's power Grid.

### THE RICKENBACKER JUMP
During the events of Episode 6 ("Cutter's Run"), Axel used the module to override the LeMans' governor, dumping raw voltage into the Nitro-injection system. The result was a successful 100-foot leap across the broken causeway, clearing the gap that claimed three Vanguard pursuit vehicles.

### WARNING
The module is internally booby-trapped with a thermal-erase trigger. Any attempt to open the casing without the proper Vanguard de-scrambler will result in a localized magnesium fire.
